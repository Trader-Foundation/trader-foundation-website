# Raw transcripts

**Immutable. Never edited in place.**

Drop module transcripts here exactly as the transcription tool produces them, mangled proper nouns and all. Nothing in this directory is corrected, cleaned, or trimmed.

Every transformation writes to a new location so errors stay traceable. If a glossary replacement turns out to be wrong, the original wording has to still exist somewhere to catch it. The "noose" to "news" correction is the case in point: it is context dependent, and being able to read the original line is what makes verification possible.

Naming: `module-NN.txt`, zero padded.

Each transcript needs a recording date and a status of CURRENT, SUPERSEDED, or RETIRED before it enters the pipeline. Superseded material either stays out or defers to the rulings layer.

Next stop in the pipeline: glossary pass, output to `../clean/`.
